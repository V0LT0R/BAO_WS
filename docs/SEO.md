# Поиск по имени и разделам сайта

9 ноября 2026 года карта `https://bao-cv.com/sitemap.xml` повторно отправлена через существующий ресурс `https://bao-cv.com/` в Google Search Console. Google обработал её со статусом «Успешно» и обнаружил 21 страницу. Для `https://bao-cv.com/ru/experience.html` отдельно принят запрос индексации и подтверждено добавление в очередь сканирования. Обнаружение страниц не означает завершённую индексацию. Все 21 опубликованный URL проверены: HTTP 200, локализованный HTML, canonical и взаимные hreflang.

Публичные страницы имеют отдельные адреса для трёх языков: английский — в корне сайта, украинский — `/uk/`, русский — `/ru/`. Главные страницы: `https://bao-cv.com/`, `https://bao-cv.com/uk/index.html`, `https://bao-cv.com/ru/index.html`. Пример раздела: `https://bao-cv.com/ru/experience.html` — «Опыт и образование Белощицкого Андрея».

Сборка заранее создаёт HTML с именем, текстами, уникальными title/description, canonical и взаимными hreflang. Язык определяется адресом, а не настройкой localStorage или страной посетителя. Код украинского языка в HTML и hreflang — `uk`; внутренний ключ переводов `ua` сохранён для совместимости с существующими данными.

Главные страницы содержат разметку ProfilePage и Person, разделы — CollectionPage/WebPage и BreadcrumbList. Варианты имени на трёх языках, должность и ссылки ORCID/Scopus/Google Scholar сверены с [ORCID](https://orcid.org/0000-0001-9548-1959) и [руководством Astana IT University](https://astanait.edu.kz/ru/board). Разметка не содержит вымышленных отзывов, рейтингов или достижений. Фото для карточки ссылки — портрет с главной страницы.

`dist/sitemap.xml` и `dist/robots.txt` генерируются из тех же списков страниц и адреса `SITE_URL`, что и HTML. Не создавайте отдельные копии в `public`: они могут устареть. Sitemap содержит только 21 публичный канонический URL. Время сборки не выдаётся за дату изменения содержания.

Публичные списки записей по-прежнему загружаются React из API. robots разрешает обход только нужных публичных GET-адресов и изображений, чтобы поисковики могли отрисовать страницы. JSON-ответы API получают `X-Robots-Tag: noindex`; изображения не получают этот запрет. Личные API остаются закрыты robots и проверками авторизации. Страницы входа, аккаунта и админки используют noindex; они не запрещены в robots, чтобы поисковик мог прочитать noindex. robots не является средством защиты данных.

В базе остаются английские и украинские поля: русская версия переводит интерфейс и описания разделов, а записи администратора показывает на исходном украинском/английском языке с пояснением и корректным атрибутом lang. Автоматического перевода научных фактов и изменений базы не выполняется.

## После публикации

1. В [Google Search Console](https://search.google.com/search-console) откройте ресурс `bao-cv.com` или `https://bao-cv.com/` и отправьте `https://bao-cv.com/sitemap.xml` через Sitemaps. Существующий файл проверки Google сохранён; наличие файла само по себе не означает, что текущий аккаунт подтвердил доступ.
2. Через URL Inspection проверьте главные страницы трёх языков и страницы опыта/публикаций, выполните Test live URL, затем Request indexing для основных URL. Проверяйте URL в том ресурсе, который охватывает HTTPS-версию сайта.
3. При наличии аккаунта [Bing Webmaster Tools](https://www.bing.com/webmasters/) отправьте ту же карту сайта. Не используйте устаревшие ping-URL или сервисы, обещающие гарантированную индексацию.
4. Смотрите отчёты Pages и Performance: доступны ли страницы для индексации, по каким запросам они показываются, есть ли показы/переходы по трём написаниям имени.

Изменения помогают поисковикам находить и понимать сайт, но не гарантируют включение в индекс, конкретное место или срок появления результатов. Для узнаваемости полезны настоящие ссылки на сайт из официального профиля университета, ORCID и Google Scholar; редактирование этих внешних профилей в эту работу не входит.

Официальные рекомендации Google: [языковые версии](https://developers.google.com/search/docs/specialty/international/localized-versions), [ProfilePage](https://developers.google.com/search/docs/appearance/structured-data/profile-page), [noindex](https://developers.google.com/search/docs/crawling-indexing/block-indexing), [запрос повторного обхода](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl).
